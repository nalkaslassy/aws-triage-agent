# Security Policy

AWS Triage Agent is an experimental alpha and is not production-ready.

Please report vulnerabilities privately to the repository owner before opening a public issue when disclosure could expose credentials, telemetry, customer data, signed requests, or an exploitable weakness. Do not include real production telemetry or credentials in issues.

For supported access patterns, data-handling limits, IAM guidance, and known security boundaries, see [docs/SECURITY.md](docs/SECURITY.md).

The project does not currently provide a formal security SLA. Live AWS and Bedrock behavior have not been validated for the v0.1.0-alpha release.
